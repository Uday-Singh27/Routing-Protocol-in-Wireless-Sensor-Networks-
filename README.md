# Routing-Protocol-in-Wireless-Sensor-Networks-
Routing Protocol in Wireless Sensor Networks:  A research &amp; implementation repository on Routing Protocols in Wireless Sensor Networks (WSN). Covers LEACH, PEGASIS, SPIN, AODV, DSR &amp; more. Includes concepts, comparisons, simulations &amp; notes.

What are Wireless Sensor Networks?
A Wireless Sensor Network (WSN) is a network of spatially distributed
autonomous sensors that monitor physical or environmental conditions
(temperature, sound, pressure, motion, etc.) and cooperatively pass data
through the network to a main location — called the Base Station (BS)
or Sink Node

WSNs are widely used in:
-  Smart Agriculture
-  Healthcare & Patient Monitoring
-  Industrial Automation
-  Environmental Monitoring
-  Military Surveillance
-  Smart Cities & IoT
